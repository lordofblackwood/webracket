27 Library: console🔗

 (include-lib console)

 Compile option:  --ffi console

The browser console is a developer tool built into every browser. It shows messages, warnings, errors, and debug output from a web page.

The console library provides the checked console-* wrappers on top of the raw js-console-* bindings from ffi/console.ffi.

Use it when you want to write messages, build collapsible groups, inspect values, or track timers and counters from WebRacket code.

27.1 Console Quick Start🔗

The browser console is a built-in developer panel that shows messages, warnings, errors, and debug output from a web page. Open the browser Developer Tools and select the Console tab.

(include-lib console)
 
; Print a message to the console.
(console-log "hello" 42)
 
; Show a warning message.
(console-warn "something looks odd")
 
; Start or increment a counter named requests.
(console-count 'requests)
 
; Start a timer named render.
(console-time 'render)
 
; This whole block can be pasted into a WebRacket page.

27.2 Console Examples🔗

; Labels may be symbols or strings.
; Start a counter using a symbol label.
(console-count 'requests)
; Reset the same counter using a string label.
(console-count-reset "requests")
 
; Group related output together.
; Open a group titled load.
(console-group "load")
; Write a message inside the group.
(console-log "starting")
; Close the current group.
(console-group-end)
 
; Inspect tabular data and timer checkpoints.
; Show a two-column table.
(console-table (vector 1 2 3) (vector "id"))
; Record a timer checkpoint with extra context.
(console-time-log 'render "phase" "layout")

27.3 Console API Reference🔗

27.3.1 Core Logging🔗

procedure

(console-log v ...) → void?

  v : any/c

 MDN  Console: log() method

Writes a log message to the browser console.

(console-log "hello" 42)
(console-log "user" 'alice)

procedure

(console-info v ...) → void?

  v : any/c

 MDN  Console: info() method

Writes an informational message to the browser console.

; Show an informational message.
(console-info "server ready")

procedure

(console-warn v ...) → void?

  v : any/c

 MDN  Console: warn() method

Writes a warning message to the browser console.

procedure

(console-error v ...) → void?

  v : any/c

 MDN  Console: error() method

Writes an error message to the browser console.

; Show an error message.
(console-error "connection failed")

procedure

(console-debug v ...) → void?

  v : any/c

 MDN  Console: debug() method

Writes a debug message to the browser console.

procedure

(console-assert condition v ...) → void?

  condition : any/c
  v : any/c

 MDN  Console: assert() method

Writes an assertion failure message when condition is false.

; Write nothing because the condition is true.
(console-assert (< 1 2) "math still works")
; Write an assertion failure message because the condition is false.
(console-assert #f "something went wrong")

27.3.2 Inspection🔗

procedure

(console-clear) → void?

 MDN  Console: clear() method

Clears the console output.

procedure

(console-dir v [options]) → void?

  v : any/c
  options : any/c = #f

 MDN  Console: dir() method

Inspects a value in the console.

(define opts (js-eval "({depth: 2})"))
(console-dir "widget" opts)

procedure

(console-dirxml v ...) → void?

  v : any/c

 MDN  Console: dirxml() method

Inspects XML/HTML output in the console.

; Inspect an XML or HTML value in the console.
(console-dirxml (vector 'p "hello"))

procedure

(console-table data [columns]) → void?

  data : any/c
  columns : any/c = #f

 MDN  Console: table() method

Displays tabular data in the console.

; Show a one-column table with an explicit column label.
(console-table (vector 1 2 3) (vector "id"))
; Show a two-column table from row data.
(console-table (vector (vector "a" 1) (vector "b" 2)) (vector "name" "count"))

procedure

; Start a collapsed group for related output.

procedure

(console-group-end) → void?

 MDN  Console: groupEnd() method

Ends the current console group.

27.3.4 Counters and Timers🔗

procedure

(console-count [label]) → void?

  label : (or/c #f string? symbol?) = #f

 MDN  Console: count() method

Increments and displays a counter.

If label is provided, symbols and strings are accepted and the wrapper converts symbols to strings before calling the browser API.

procedure

(console-count-reset [label]) → void?

  label : (or/c #f string? symbol?) = #f

 MDN  Console: countReset() method

Resets a counter.

procedure

(console-time [label]) → void?

  label : (or/c #f string? symbol?) = #f

 MDN  Console: time() method

Starts a timer.

If label is provided, symbols and strings are accepted and the wrapper converts symbols to strings before calling the browser API.

procedure

(console-time-end [label]) → void?

  label : (or/c #f string? symbol?) = #f

 MDN  Console: timeEnd() method

Ends a timer.

If label is provided, symbols and strings are accepted and the wrapper converts symbols to strings before calling the browser API.

procedure

(console-time-log [label] v ...) → void?

  label : (or/c #f string? symbol?) = #f
  v : any/c

 MDN  Console: timeLog() method

Logs the current value of a timer and any additional data.

(console-time-log 'render "phase" "layout")

procedure

(console-time-stamp [label]) → void?

  label : (or/c #f string? symbol?) = #f

 MDN  Console: timeStamp() method

Adds a timeline marker.

If label is provided, symbols and strings are accepted and the wrapper converts symbols to strings before calling the browser API.

; Add a timeline marker named startup.
(console-time-stamp 'startup)
