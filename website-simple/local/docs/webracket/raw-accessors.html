53 Raw Accessors🔗

This appendix collects the raw bridge accessors for the core wrapper libraries in one place. Use the checked wrappers by default and reach for these accessors only when you explicitly need the underlying browser object.

53.1 Window Raw Accessor🔗

procedure

(dom-window-raw win) → external/raw

  win : any/c
Returns the wrapped browser Window object.

procedure

(window-document-info-raw doc) → external/raw

  doc : any/c
Returns the wrapped browser Document object stored in the Window wrapper.

procedure

(window-location-info-raw loc) → external/raw

  loc : any/c
Returns the wrapped browser Location object stored in the Window wrapper.

procedure

(media-query-list-raw query) → external/raw

  query : any/c
Returns the wrapped browser MediaQueryList object.

procedure

(css-style-declaration-raw style) → external/raw

  style : any/c
Returns the wrapped browser CSSStyleDeclaration object.
