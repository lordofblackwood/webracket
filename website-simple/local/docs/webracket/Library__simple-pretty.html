18 Library: simple-pretty🔗

 (include-lib simple-pretty)

The simple-pretty library formats Racket values as readable pretty-printed text. It is useful when you want a predictable pretty-printer without depending on the full Racket pretty-printing stack.

It provides four entry points:

  • simple-pretty-print for writing to the current output port

  • simple-pretty-write for printing in a write-style format

  • simple-pretty-display for printing in a display-style format

  • simple-pretty-format for producing a formatted string

The printer is controlled by an association list of options. The default settings are stored in default-pretty-options. Common options include the line width, nesting depth, whether to append a newline, whether to show exactness prefixes, and whether to abbreviate read macros such as quote and quasiquote.

The options list is an association list of (cons key value) pairs. If the same option appears more than once, the later entry wins.

18.1 Quick Start🔗

Start by including the library and formatting a small value.

(include-lib simple-pretty)
 
(simple-pretty-format '(1 2 3))
; => "(1 2 3)"

18.2 Examples🔗

Use simple-pretty-format when you want a string result.

(simple-pretty-format ''(alpha beta))
; => "'(alpha beta)"

Use simple-pretty-write or simple-pretty-display when you want to send the formatted text directly to a port.

(simple-pretty-write '(1 2 3))
; writes "(1 2 3)" to the current output port
(simple-pretty-display "hello world")
; writes "hello world" to the current output port

18.3 Options🔗

value

default-pretty-options : list?

The default pretty-print configuration.

The current defaults are:

  • 'columns 79 - break lines when a rendered line would exceed 79 columns. Use 'infinity to disable width-based line breaking.

  • 'depth #f - do not limit nesting depth. Set it to a nonnegative integer to replace deeper values with "...".

  • 'newline? #t - append a trailing newline when writing to a port.

  • 'show-inexactness #f - print numbers with Racket’s standard write-like number formatting, which shows inexactness prefixes when needed.

  • 'exact-as-decimal #f - render exact rational numbers as decimal notation when the conversion is finite and still exact enough to print cleanly.

  • '.-symbol-without-bars #f - print the symbol '|.| as "." instead of the bar-quoted symbol form.

  • 'abbreviate-read-macros #t - use the usual read-macro abbreviations for quoted forms, such as quote, quasiquote, unquote, unquote-splicing, syntax, quasisyntax, unsyntax, and unsyntax-splicing.

Supplying options works like this:

(simple-pretty-format '(1 2 3)
                      '((columns . 20)
                        (newline? . #f)
                        (abbreviate-read-macros . #t)))

Each option is validated before it is used. The accepted value shapes are:

  • 'columns accepts an exact integer or 'infinity.

  • 'depth accepts #f or a nonnegative exact integer.

  • 'newline?, 'show-inexactness, 'exact-as-decimal, '.-symbol-without-bars, and 'abbreviate-read-macros all accept booleans.
