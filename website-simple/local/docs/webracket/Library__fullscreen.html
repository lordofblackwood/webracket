36 Library: fullscreen🔗

 (require fullscreen) package: fullscreen

 Safari warning. Do not expect this wrapper to work in Safari. MDN marks the Fullscreen API as Limited availability, and Safari is the main browser to treat as unavailable here.

The fullscreen module wraps the browser Fullscreen API for the current document and its elements.

 MDN  Fullscreen API

Read the MDN page first. The wrapper below shows the WebRacket surface, while the MDN documentation explains permission rules, user activation requirements, and browser differences around fullscreen behavior.

Use fullscreen when you want to:

  • check whether fullscreen requests are available

  • read the current fullscreen element

  • request fullscreen for a specific element

  • exit fullscreen and listen for fullscreenchange

36.1 Fullscreen Quick Start🔗

(require browser/document
         fullscreen)
 
(define panel (document-get-element-by-id "panel"))
 
(when panel
  (fullscreen-request! panel))

36.2 Fullscreen API🔗

procedure

(fullscreen-supported?) → boolean?

Returns #t when the current document exposes the core Fullscreen API methods used by this wrapper.

procedure

(fullscreen-enabled?) → boolean?

 MDN  Document: fullscreenEnabled property

Returns the current document’s fullscreenEnabled value.

procedure

(fullscreen-element) → (or/c #f dom-element?)

 MDN  Document: fullscreenElement property

Returns the current fullscreen element, or #f when no element is active.

procedure

(fullscreen-active?) → boolean?

Returns #t when (fullscreen-element) is non-#f.

procedure

(fullscreen-request! element) → js-promise?

  element : (or/c dom-element? external?)

 MDN  Element: requestFullscreen() method

Requests fullscreen display for element and returns the browser Promise as a wrapped js-promise?.

procedure

(fullscreen-exit!) → js-promise?

 MDN  Document: exitFullscreen() method

Requests exit from fullscreen mode and returns the browser Promise as a wrapped js-promise?.

procedure

(fullscreen-add-change-listener! callback) → external/raw

  callback : (or/c procedure? external?)

 MDN  Document: fullscreenchange event

Adds a fullscreenchange listener to the current document and returns the installed callback value.

procedure

(fullscreen-remove-change-listener! callback) → void?

  callback : (or/c procedure? external?)
Removes a previously installed fullscreenchange listener.

procedure

(fullscreen-add-error-listener! callback) → external/raw

  callback : (or/c procedure? external?)

 MDN  Document: fullscreenerror event

Adds a fullscreenerror listener to the current document and returns the installed callback value.

procedure

(fullscreen-remove-error-listener! callback) → void?

  callback : (or/c procedure? external?)
Removes a previously installed fullscreenerror listener.
