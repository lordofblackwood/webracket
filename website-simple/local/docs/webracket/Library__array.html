17 Library: array🔗

 (include-lib array)

 Compile option:  --ffi array

The array library is the recommended way to work with JavaScript arrays. It provides functions for constructing and indexing JavaScript arrays from Racket, along with helpers for moving between JavaScript arrays and Racket vectors or lists.

Use array when you want to:

  • build a JavaScript array from Racket values

  • read array elements or lengths

  • convert a JavaScript array to a vector or list

  • convert a byte array or typed array to Racket bytes

  • apply the common non-callback Array methods used by WebRacket

Arrays returned by this library are "checked wrapper structures". That is, an array value is a Racket structure that holds a raw JavaScript array and validates operations before crossing the bridge. Use array-raw only when you need to pass the underlying browser value to a low-level bridge helper or to an API that has not yet been wrapped.

When an array value is displayed, the wrapped JavaScript elements are shown in a vector-like form. This display is only a readable representation of the underlying browser array; it is not a Racket vector.

The expensive direction is converting JavaScript arrays into Racket values. To keep this efficient, array->vector uses a bulk bridge helper instead of walking the array one element at a time through the WebRacket bridge. The list conversion array->list reuses this vector path, and array->bytes uses the same bulk approach for byte arrays and typed arrays.

String-like arguments accept either strings or symbols. Optional arguments use #f to indicate that the argument is omitted.

17.1 Array Quick Start🔗

Start by including the array library, building an array, and converting it back to a Racket vector.

; Include the array helper library.
(include-lib array)
 
; Build a JavaScript array.
(define arr (array-of 1 2 3))
 
; The result is a checked wrapper, not a raw browser object.
(array? arr)
 
; Read it back as a Racket vector.
(array->vector arr)
 
; Use the raw accessor only when you need the underlying browser value.
(array-raw arr)

17.2 Examples🔗

These examples show the most common array operations and their results.

17.2.1 Construction and Conversion🔗

(define arr (array-of 1 2 3))
(array? arr)

  #t

(array->vector arr)

  #(1 2 3)

(vector->array '#(4 5 6))

  (array '#(4 5 6))

That result is a checked array wrapper around a JavaScript array with the elements 4, 5, and 6.

(array-from (array-raw arr))

  (array '#(1 2 3))

(array-from (vector->array '#(7 8 9)))

  (array '#(7 8 9))

(array-from-async (array-raw arr))

  (array '#(1 2 3))

(array-from (vector->array '#(1 2 3))
            (lambda (value index) (+ value index)))

  (array '#(1 3 5))

The next example uses the optional this-arg slot. The callback still returns the same numbers, but the third argument is now being forwarded as the JavaScript this binding.

(array-from (vector->array '#(1 2 3))
            (lambda (value index)
              (+ value index))
            'ignored-this)

  (array '#(1 3 5))

(array-to-string arr)

  "1,2,3"

17.2.2 Inspection🔗

(array-length arr)

  3

(array-ref arr 1)

  2

(array-join arr ",")

  "1,2,3"

(array-to-locale-string arr)

  "1,2,3"

17.2.3 Mutation and Derived Copies🔗

(array-slice arr 1 3)

  (array '#(2 3))

(array-concat arr 4 5)

  (array '#(1 2 3 4 5))

(array-fill! (vector->array '#(1 2 3 4)) 9 1 3)

  (array '#(1 9 9 4))

(array-copy-within! (vector->array '#(1 2 3 4)) 2 0 2)

  (array '#(1 2 1 2))

(array-sort! (vector->array '#(3 1 2)))

  (array '#(1 2 3))

(array-to-sorted (vector->array '#(3 1 2)))

  (array '#(1 2 3))

(array-flat (array-of 1 (array-of 2 3)) 1)

  (array '#(1 2 3))

(array-with arr 1 99)

  (array '#(1 99 3))

(array-splice! (vector->array '#(1 2 3 4)) 1 2 9 8)

  (array '#(2 3))

17.4 Array Conversion Helpers🔗

procedure

(array-from source [map-function this-arg]) → array?

  source : any/c
  map-function : (or/c procedure? external?) = #f
  this-arg : any/c = #f
Builds an array from an iterable or array-like value.

If map-function is supplied, it is called with each source value and its index, and its result becomes the next array item. The optional this-arg value is used as the JavaScript this value while calling map-function.

Builds an array from an async iterable or array-like value.
