47 Library: screen-orientation🔗

 (require screen-orientation) package: screen-orientation

The screen-orientation module wraps the browser screen.orientation object. Use it to read the current orientation, watch for orientation changes, and request an orientation lock when the browser allows it.

 MDN  Screen Orientation API

Read MDN first. Screen-orientation locking has browser and context restrictions. In particular, MDN notes that locking is usually limited to mobile devices and browsers commonly require fullscreen or a similar installed-app context.

47.1 Screen Orientation Quick Start🔗

(require browser/dom
         screen-orientation)
 
(define orientation (screen-orientation))
 
(when orientation
  (js-log (screen-orientation-type orientation))
  (screen-orientation-add-change-listener!
   orientation
   (lambda (event)
     (js-log (screen-orientation-type orientation))
     (void))))

47.2 Screen Orientation API🔗

procedure

(screen-orientation-supported?) → boolean?

 MDN  Screen: orientation property

Returns #t when screen.orientation is available.

procedure

(screen-orientation) → (or/c #f screen-orientation?)

Returns the current ScreenOrientation object wrapped in a checked value, or #f when unsupported.

procedure

(screen-orientation? v) → boolean?

  v : any/c
Returns #t for wrapped ScreenOrientation values.

procedure

(screen-orientation-raw value) → external/raw

  value : screen-orientation?
Returns the wrapped raw browser object.

procedure

(screen-orientation-type value) → string?

  value : screen-orientation?

 MDN  ScreenOrientation: type property

Returns an orientation type such as "portrait-primary" or "landscape-primary".

procedure

(screen-orientation-angle value) → number?

  value : screen-orientation?

 MDN  ScreenOrientation: angle property

Returns the orientation angle in degrees.

procedure

(screen-orientation-lock-type? v) → boolean?

  v : any/c
Returns #t for strings or symbols accepted by ScreenOrientation.lock: 'any, 'natural, 'landscape, 'portrait, 'portrait-primary, 'portrait-secondary, 'landscape-primary, and 'landscape-secondary.

procedure

(screen-orientation-lock! value lock-type) → js-promise?

  value : screen-orientation?
  lock-type : screen-orientation-lock-type?

 MDN  ScreenOrientation: lock() method

Requests an orientation lock and returns the browser Promise.

procedure

(screen-orientation-unlock! value) → void?

  value : screen-orientation?

 MDN  ScreenOrientation: unlock() method

Removes an active orientation lock.

procedure

(screen-orientation-on-change! value    
  callback) → void?
  value : screen-orientation?
  callback : (or/c procedure? external? #f)
Sets the onchange handler. Pass #f to clear it.

procedure

(screen-orientation-add-change-listener! value 
  callback) 
 → external/raw
  value : screen-orientation?
  callback : (or/c procedure? external?)
Adds a change listener and returns the installed external callback.

procedure

(screen-orientation-remove-change-listener! value    
  callback) → void?
  value : screen-orientation?
  callback : (or/c procedure? external?)
Removes a previously installed change listener.
