40 Library: image🔗

 (include-lib image)

 Compile option:  --ffi dom

The image library wraps HTML image elements in checked values.

Images load and display pictures. An image element tracks its source URL, its loading state, and its natural size once the browser has fetched it.

Use image when you want to:

  • create a new image element

  • set the source URL or alternative text

  • check whether the image has finished loading

  • read the browser’s current source URL

The image library covers image creation and common image properties.

String-like image properties accept either strings or symbols. Optional size arguments use #f to mean that the argument is omitted.

40.1 Image Quick Start🔗

Start by creating an image element, pointing it at a source, and then checking whether the browser has finished loading it.

; Include the checked image wrapper library.
(include-lib image)
 
; Create a new image element.
(define img (image-new))
 
; Set the image source and a short description.
(image-set-src! img "/images/logo.png")
(image-set-alt! img "Project logo")
 
; Ask whether the browser has finished loading it.
(image-complete? img)

The quick start shows the main pattern: create the image, configure it, and then read the browser’s loading state.

40.2 Image Example🔗

This example shows how to prepare an image for display and then inspect the browser’s view of it.

; Include the image wrapper library.
(include-lib image)
 
; Create an image element and configure it before use.
(define img (image-new))
(image-set-src! img "/images/logo.png")
(image-set-alt! img "Project logo")
 
; Read the current source URL and loading state.
(define current (image-src img))
(define loaded? (image-complete? img))
 
(void current loaded?)

If you just need the basics, the main entry points are image-new, image-src, image-set-src!, image-set-alt!, and image-complete?.
