41 Library: indexed-db🔗

 (include-lib indexed-db)

 Compile option:  --ffi dom

IndexedDB is the browser’s low-level database API for storing larger structured data sets on the client. It is asynchronous and more powerful than Web Storage, which makes it a better fit for applications that need to query or update persistent browser data without blocking the page.

In WebRacket, the indexed-db library provides a checked wrapper for the browser’s IndexedDB factory object. It gives programs a more direct entry point than the lower-level window-indexed-db accessor while keeping the browser object wrapped in a Rackety value.

 MDN  IndexedDB API

Use indexed-db when you want to:

  • open and delete databases

  • compare IndexedDB keys

  • inspect the browser’s IndexedDB factory object

41.1 IndexedDB Quick Start🔗

; Include the IndexedDB wrapper library.
(include-lib indexed-db)
 
; Get the browser's IndexedDB factory object.
(define db (indexed-db))
 
; Open a database.
(define req (indexed-db-open db "demo-db"))
 
(void db req)
