55.2 WebRacket-specific Forms🔗

syntax

(require-lib lib-id)

Racket docs: require-lib
WebRacket note: Requires a WebRacket library by identifier. Valid only at module top level.

syntax

(include-lib lib-id)

Racket docs: include-lib
WebRacket note: Includes a WebRacket library source file by identifier. Valid only at module top level.

syntax

(#%app f arg ...)

Racket docs: #%app
WebRacket note: Application rewrites keyword tokens to keyword values so keyword-call surface syntax works in ordinary call positions.

syntax

(#%module-begin form ...)

Racket docs: #%module-begin
WebRacket note: Language-specific module-begin for #lang webracket.
