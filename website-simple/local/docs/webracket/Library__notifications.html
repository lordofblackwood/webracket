44 Library: notifications🔗

 (require notifications) package: notifications

The notifications module wraps the browser Notification API. It provides a checked wrapper for notification instances plus a promise-based permission request helper.

 MDN  Notifications API

Important browser constraints

  • Notifications may be unavailable in some browsers or contexts.

  • Most browsers require a user gesture before prompting for permission.

  • Permission requests are asynchronous and return js-promise? values.

44.1 Quick Start🔗

(require notifications
         js/promise)
 
(js-promise-then
 (notification-request-permission)
 (lambda (permission)
   (when (equal? permission "granted")
     (make-notification "Hello from WebRacket"))))

  value : notification?

procedure

(notification-permission) → (or/c #f string?)

Returns the current browser notification permission string, or #f when the API is unavailable.

procedure

(notification-request-permission) → js-promise?

Starts an asynchronous browser permission request.
