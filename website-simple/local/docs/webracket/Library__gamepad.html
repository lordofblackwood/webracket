37 Library: gamepad🔗

 (require gamepad) package: gamepad

The gamepad module wraps the browser Gamepad API: polling navigator.getGamepads, reading axes/buttons, and listening for connect/disconnect events.

 MDN  Gamepad API

Read MDN first. Browsers do not expose gamepad state until the user has interacted with the page or pressed a button on a connected gamepad. The live state is normally polled from an animation loop.

37.1 Gamepad Quick Start🔗

(require browser/dom
         gamepad)
 
(when (gamepad-supported?)
  (gamepad-add-connected-listener!
   (lambda (event)
     (define gp (gamepad-event-gamepad event))
     (when gp
       (js-log (gamepad-id gp)))
     (void))))

37.2 Gamepad API🔗

procedure

(gamepad-supported?) → boolean?

 MDN  Navigator: getGamepads() method

Returns #t when navigator.getGamepads is available.

procedure

(gamepads) → vector?

Returns a vector of current gamepad slots. Disconnected or empty slots are represented as #f, matching the nullable slots in the browser API.

procedure

(gamepad? v) → boolean?

  v : any/c
Returns #t for wrapped Gamepad values.

procedure

(gamepad-raw value) → external/raw

  value : gamepad?
Returns the wrapped raw Gamepad object.

procedure

(gamepad-event-gamepad event) → (or/c #f gamepad?)

  event : external/raw
Extracts the wrapped Gamepad from a gamepadconnected or gamepaddisconnected event.

procedure

(gamepad-id value) → string?

  value : gamepad?
Returns the gamepad id string.

procedure

(gamepad-index value) → exact-nonnegative-integer?

  value : gamepad?
Returns the gamepad slot index.

procedure

(gamepad-connected? value) → boolean?

  value : gamepad?
Returns whether the gamepad is connected.

procedure

(gamepad-timestamp value) → number?

  value : gamepad?
Returns the browser gamepad timestamp.

procedure

(gamepad-mapping value) → string?

  value : gamepad?
Returns the mapping string, commonly "standard".

procedure

(gamepad-axes value) → vector?

  value : gamepad?
Returns axis values as numbers.

procedure

(gamepad-buttons value) → vector?

  value : gamepad?
Returns wrapped GamepadButton values.

procedure

(gamepad-button? v) → boolean?

  v : any/c
Returns #t for wrapped GamepadButton values.

procedure

(gamepad-button-raw value) → external/raw

  value : gamepad-button?
Returns the wrapped raw GamepadButton object.

procedure

(gamepad-button-pressed? value) → boolean?

  value : gamepad-button?
Returns whether the button is pressed.

procedure

(gamepad-button-touched? value) → boolean?

  value : gamepad-button?
Returns whether the button is touched.

procedure

(gamepad-button-value value) → number?

  value : gamepad-button?
Returns the analog button value between 0 and 1.

procedure

(gamepad-add-connected-listener! callback) → external/raw

  callback : (or/c procedure? external?)
Adds a gamepadconnected listener to window.

procedure

(gamepad-remove-connected-listener! callback) → void?

  callback : (or/c procedure? external?)
Removes a previously installed gamepadconnected listener.

procedure

(gamepad-add-disconnected-listener! callback) → external/raw

  callback : (or/c procedure? external?)
Adds a gamepaddisconnected listener to window.

procedure

(gamepad-remove-disconnected-listener! callback) → void?

  callback : (or/c procedure? external?)
Removes a previously installed gamepaddisconnected listener.
