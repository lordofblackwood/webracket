21 Library: rquery🔗

 (include-lib rquery)

The rquery library provides a small set of tools for finding DOM elements and working with the resulting selections.

The rquery library is still experimental. Its API may change as the selection helpers settle.

Use rquery when you want to:

  • select elements with CSS selectors

  • inspect the size or contents of a selection

  • map or iterate over selected elements

  • chain a selection through $chain and dot-prefixed helper calls

Currently, selectors accept strings only. Helper functions such as element-set-text-content! accept the same values as documented in the underlying DOM libraries.

21.1 QuickStart🔗

Start by including the library, building a small page sample, selecting a heading, and reading its text.

The page sample is equivalent to <div id="rquery-root"><h1 id="hw">Hello World!</h1></div>.

(include-lib document)
(include-lib sxml)
(include-lib rquery)
 
; Build a small page sample in the current document.
(define at (string->symbol "@"))
(define page
  (sxml->dom
   `(div (,at (id "rquery-root"))
         (h1 (,at (id "hw"))
             "Hello World!"))))
 
(element-append! (document-body) page)
 
; Select the heading by id.
(define sel ($ "#hw"))
 
; Read the text from the first selected element.
(.text sel)
; => "Hello World!"

The $chain macro gives you a convenient left-to-right style for selection workflows:

($chain ($ "#hw")
        .text)
; => "Hello World!"

21.2 Examples🔗

These examples show the most common selection operations.

21.2.1 Selecting Elements🔗

(define sel ($ ".card"))

($selection? sel)
; => #t
($length sel)
; => 0

21.2.2 Inspecting a Selection🔗

(define first-card ($first ($ ".card")))

When the selection is empty, $first returns #f.

(define nodes ($selection->vector ($ ".card")))

21.2.3 Attributes🔗

Use the attribute helpers to read state from the first selected element.

(define hw ($ "#hw"))
($attr hw "id")
; => "hw"
(.attr hw 'id)
; => "hw"
($has-attr? hw "id")
; => #t

21.2.4 Classes🔗

Use the class helpers to inspect and update the first selected element.

(define card ($ ".card"))
($has-class? card "card")
; => #t
($add-class! card "is-highlighted")
($remove-class! card "card")

21.2.5 Text, Values, and Data🔗

Use the text, value, and data helpers to update common UI state.

(define note ($ "#text-host"))
($text! note "Updated text")
 
(define field ($ "#value-host"))
($val field)
; => "initial"
($val! field "updated")
 
(define meta ($ "#data-host"))
($data meta "state")
; => "cold"
($data! meta "state" "warm")

21.2.6 Finding Descendants🔗

Use $find to search within each selected element.

(define cards ($ ".card"))
($length ($find cards ".name"))
; => 2
($chain cards
        .find
        ".tag"
        .map
        element-text-content)
; => a selection of tag labels

21.2.7 Children and Parents🔗

Use the child and parent helpers to move around the DOM tree.

(define cards ($ ".card"))
($length ($children cards))
; => 4
($length ($parent ($find cards ".name")))
; => 2

21.2.8 Closest Ancestors🔗

Use $closest to walk upward to the nearest matching ancestor.

(define leaves ($ ".leaf"))
($length ($closest leaves "section"))
; => 3
($chain leaves
        .closest
        "section"
        .map
        element-id)
; => a selection of section ids

21.2.9 Sibling Navigation🔗

Use $next and $prev to walk sideways through sibling elements.

(define leaves ($ ".leaf"))
($length ($next leaves))
; => 1
($length ($prev ($next leaves)))
; => 1
(define first-leaf ($first leaves))
($length ($siblings (list->$selection (list first-leaf))))
; => 1

21.2.10 Iterating and Mapping🔗

($chain ($ ".card")
        .for-each
        (lambda (node)
          (element-set-attribute! node 'data-seen 'yes)))
($chain ($ ".card")
        .map
        (lambda (node)
          (element-text-content node)))
($chain ($ ".card")
        .filter
        (lambda (node)
          (equal? (element-id node) "card-2"))
        .map
        element-text-content)
; => a selection containing the second card text
($chain ($ ".card")
        .where
        (lambda (node)
          (equal? (element-id node) "card-2"))
        .map
        element-text-content)
; => a selection containing the second card text
($chain ($ ".card")
        .not
        (lambda (node)
          (equal? (element-id node) "card-2"))
        .map
        element-id)
; => a selection containing the first card id

21.2.11 Event Handlers🔗

Use .on to attach DOM event listeners to each selected element.

(include-lib event)
(define clicks 0)
 
($chain ($ "#hw")
        .on
        "click"
        (lambda (evt)
          (set! clicks (add1 clicks))))
 
clicks
; => 0

Event handlers receive the raw browser event value, so helpers such as event-type and prevent-default! are available after (include-lib event).

Use .once when you want a listener to fire only one time.

(define once-count 0)
 
($chain ($ "#hw")
        .once
        "click"
        (lambda (evt)
          (set! once-count (add1 once-count))))
 
once-count
; => 0

After the first event, the listener removes itself automatically.

Use .trigger when you want to dispatch an event from code.

(define trigger-count 0)
 
($chain ($ "#hw")
        .on
        "click"
        (lambda (evt)
          (set! trigger-count (add1 trigger-count))))
 
($chain ($ "#hw")
        .trigger
        "click")
 
trigger-count
; => 1

Use .on-delegate when you want one listener on a parent element to react to matching descendants. The delegated listener receives the matched descendant element and the event.

(define delegate-count 0)
 
($chain ($ "#delegation-host")
        .on-delegate
        "click"
        "button"
        (lambda (matched evt)
          (set! delegate-count (add1 delegate-count))))
 
delegate-count
; => 0

Because the delegated callback gets the matching element explicitly, you can keep the handler logic focused on the item that was matched rather than the event target that bubbled up.

21.2.12 Text Content🔗

(define title ($ "#hw"))
(.text title)
; => "Hello World!"

The .text helper reads the text content of the first selected element and returns "" when the selection is empty.

21.2.13 Chaining🔗

($chain ($ "#hw") .text)
; => "Hello World!"

The last step in a $chain form may return a non-selection value. That makes it convenient to end a pipeline with a query result, a string, or any other final answer.

syntax

($chain seed .method arg ...)

Threads seed through one or more dot-prefixed helper calls. Each step receives the current selection as its first argument. The final step may return any value, including a non-selection result.
