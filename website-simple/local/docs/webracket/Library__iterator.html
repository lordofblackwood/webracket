19 Library: iterator🔗

 (include-lib iterator)

 Compile option:  --ffi standard

The iterator library gives you a checked wrapper around JavaScript’s Iterator helper objects. These helpers let you build, transform, and consume lazy streams of values without dropping down to raw browser calls.

Use this library when you want to work with the JavaScript iterator helper family from WebRacket code. The library covers the constructor, the helper prototype, the static helpers, and the common iterator-transform methods.

19.1 Iterator Values🔗

The wrapper keeps raw browser iterator objects tucked away in a single iterator struct. That gives the library room to grow with checked helpers while still letting you recover the underlying browser object when you explicitly need it. The raw accessor lives in the Raw Accessors appendix.

struct

(struct iterator (raw)
    #:extra-constructor-name make-iterator)
  raw : external/raw
Wraps a browser Iterator object in the checked struct used by the library.

19.2 Iterator Quick Start🔗

Start by including the library, turning a JavaScript iterable into an Iterator, and asking it for its first step. The resulting value is an iterator struct, not a raw browser object.

; Include the checked Iterator wrapper library.
(include-lib iterator)
 
; Create a JavaScript iterator in the browser.
(define source (js-eval "[1, 2, 3].values()"))
 
; Convert the source into the standard Iterator form.
(define iter (iterator-from source))
 
; Ask the iterator for its first step.
(define first-step (iterator-next iter))

The quick start shows the core pattern: convert an existing iterator or iterable with iterator-from, then use the Rackety wrapper functions to advance or transform the iterator.

19.3 Iterator Example🔗

This example starts with a JavaScript array, turns it into an iterator, maps each value to a new one, and then collects the results back into a WebRacket value.

; Include the Iterator wrapper library.
(include-lib iterator)
 
; Create a JavaScript iterator from an array.
(define source (js-eval "[1, 2, 3].values()"))
 
; Convert it to the standard Iterator form.
(define iter (iterator-from source))
 
; Double each value as it flows through the iterator.
(define doubled
  (iterator-map iter
                (lambda (n)
                  (* n 2))))
 
; Take the results back into a normal WebRacket value.
(define result (iterator->vector doubled))

After this code runs, result is #(2 4 6).

19.4 Iterator Helpers🔗

procedure

(iterable? value) → boolean?

  value : any/c
This predicate recognizes values that follow the JavaScript iterable protocol: they provide a callable [Symbol.iterator] method. Common iterable values include arrays, strings, Sets, Maps, and wrapped iterator values.

struct

(struct iterator-zip-options (mode padding)
    #:extra-constructor-name make-iterator-zip-options)
  mode : symbol?
  padding : any/c
This struct describes the optional MDN options object accepted by iterator-zip and iterator-zip-keyed.

The mode field selects how iterables are combined. Use one of 'shortest, 'longest, or 'strict.

The padding field is reserved for future support of the MDN padding object. Passing #f for the whole options value uses the default shortest-zip behavior.

procedure

(iterator-from object) → iterator?

  object : iterable?

 MDN  Iterator.from()

Returns a wrapped JavaScript iterator produced from object. Common inputs include arrays, strings, and other iterable JavaScript values. The value may also be an existing iterator.

procedure

(iterator-concat iterable ...) → iterator?

  iterable : iterable?

 MDN  Iterator.concat()

Concatenates several JavaScript iterables into a single iterator. Common inputs include arrays, strings, Sets, Maps, and wrapped iterator values.

procedure

(iterator-zip iterables [options]) → iterator?

  iterables : iterable?
  options : (or/c #f iterator-zip-options?) = #f

 MDN  Iterator.zip()

Zips a collection of iterables into a new iterator. Pass #f for the default shortest-zip behavior, or pass an iterator-zip-options struct to describe the MDN options object.

procedure

(iterator-zip-keyed iterables [options]) → iterator?

  iterables : iterable?
  options : (or/c #f iterator-zip-options?) = #f

 MDN  Iterator.zipKeyed()

Zips a keyed collection of iterables into a new iterator. Pass #f for the default shortest-zip behavior, or pass an iterator-zip-options struct to describe the MDN options object.

procedure

(iterator-drop iter count) → iterator?

  iter : iterator?
  count : exact-nonnegative-integer?

 MDN  Iterator.prototype.drop()

Skips the first count values from iter.

procedure

(iterator-every iter callback [this-arg]) → boolean?

  iter : iterator?
  callback : (or/c (-> any/c exact-nonnegative-integer? iterator? any/c) external?)
  this-arg : any/c = #f

 MDN  Iterator.prototype.every()

Calls callback with three arguments:

  • the yielded value,

  • the zero-based index, and

  • the wrapped source iterator.

If callback is an external browser value, it should be a browser JavaScript function. The function receives the yielded value, the zero-based index, and the wrapped source iterator. Use #f to omit this-arg. If you need a literal #f receiver, pass a thunk such as (lambda () #f). The callback result is treated as true unless it is #f. The result is #t only if every call succeeds.

procedure

(iterator-filter iter callback [this-arg]) → iterator?

  iter : iterator?
  callback : (or/c (-> any/c exact-nonnegative-integer? iterator? any/c) external?)
  this-arg : any/c = #f

 MDN  Iterator.prototype.filter()

Calls callback with the same three arguments as iterator-every. Keep the values for which the callback result is treated as true unless it is #f. If callback is an external browser value, it should be a browser JavaScript function with the same argument shape as iterator-every. Use #f to omit this-arg. If you need a literal #f receiver, pass a thunk such as (lambda () #f).

procedure

(iterator-find iter callback [this-arg]) → any/c

  iter : iterator?
  callback : (or/c (-> any/c exact-nonnegative-integer? iterator? any/c) external?)
  this-arg : any/c = #f

 MDN  Iterator.prototype.find()

Calls callback with the same three arguments as iterator-every. Returns the first yielded value for which the callback result is treated as true unless it is #f, or #f if no value matches. If callback is an external browser value, it should be a browser JavaScript function with the same argument shape as iterator-every. Use #f to omit this-arg. If you need a literal #f receiver, pass a thunk such as (lambda () #f).

procedure

(iterator-flat-map iter callback [this-arg]) → iterator?

  iter : iterator?
  callback : (or/c (-> any/c exact-nonnegative-integer? iterator? iterable?) external?)
  this-arg : any/c = #f

 MDN  Iterator.prototype.flatMap()

Calls callback with the same three arguments as iterator-every. The callback should return an iterable value, and the wrapper flattens those results one level. If callback is an external browser value, it should be a browser JavaScript function with the same argument shape as iterator-every. Use #f to omit this-arg. If you need a literal #f receiver, pass a thunk such as (lambda () #f).

procedure

(iterator-for-each iter callback [this-arg]) → void?

  iter : iterator?
  callback : (or/c (-> any/c exact-nonnegative-integer? iterator? any/c) external?)
  this-arg : any/c = #f

 MDN  Iterator.prototype.forEach()

Calls callback with the same three arguments as iterator-every. The return value is ignored. If callback is an external browser value, it should be a browser JavaScript function with the same argument shape as iterator-every. Use #f to omit this-arg. If you need a literal #f receiver, pass a thunk such as (lambda () #f).

procedure

(iterator-map iter callback [this-arg]) → iterator?

  iter : iterator?
  callback : (or/c (-> any/c exact-nonnegative-integer? iterator? any/c) external?)
  this-arg : any/c = #f

 MDN  Iterator.prototype.map()

Calls callback with the same three arguments as iterator-every. The callback result becomes the next yielded value. If callback is an external browser value, it should be a browser JavaScript function with the same argument shape as iterator-every. Use #f to omit this-arg. If you need a literal #f receiver, pass a thunk such as (lambda () #f).

procedure

(iterator-reduce iter    
  callback    
  [initial-value]) → any/c
  iter : iterator?
  callback : (or/c (-> any/c any/c exact-nonnegative-integer? iterator? any/c) external?)
  initial-value : any/c = #f

 MDN  Iterator.prototype.reduce()

Calls callback with four arguments:

  • the running accumulator,

  • the yielded value,

  • the zero-based index, and

  • the wrapped source iterator.

If callback is an external browser value, it should be a browser JavaScript function with the same argument shape as iterator-every, plus the accumulator as the first argument. Use #f to omit initial-value. If you need a literal #f initial value, pass a thunk such as (lambda () #f). The callback result becomes the next accumulator value.

procedure

(iterator-some iter callback [this-arg]) → boolean?

  iter : iterator?
  callback : (or/c (-> any/c exact-nonnegative-integer? iterator? any/c) external?)
  this-arg : any/c = #f

 MDN  Iterator.prototype.some()

Calls callback with the same three arguments as iterator-every. Returns #t as soon as one callback call produces a result that is treated as true unless it is #f. If callback is an external browser value, it should be a browser JavaScript function with the same argument shape as iterator-every. Use #f to omit this-arg. If you need a literal #f receiver, pass a thunk such as (lambda () #f).

procedure

(iterator-take iter count) → iterator?

  iter : iterator?
  count : exact-nonnegative-integer?

 MDN  Iterator.prototype.take()

Keeps only the first count values from iter.

procedure

(iterator->vector iter) → vector?

  iter : iterator?

 MDN  Iterator.prototype.toArray()

Collects the yielded values into a WebRacket vector.

19.5 Iterator Raw Accessors🔗

These helpers expose the underlying browser constructor object or raw iteration records. They are useful when you need to interoperate with lower level code.

procedure

(Iterator) → external/raw

 MDN  Iterator

Returns the JavaScript Iterator constructor/global object.

procedure

(iterator-prototype) → external/raw

 MDN  Iterator

Returns Iterator.prototype, the shared prototype for iterator helpers.

procedure

(iterator-prototype-constructor) → external/raw

 MDN  Iterator

Returns the constructor stored on Iterator.prototype.

procedure

(iterator-prototype-to-string-tag) → string?

 MDN  Iterator

Returns the default Symbol.toStringTag value for Iterator.prototype.

procedure

(iterator-next iter) → external/raw

  iter : iterator?

 MDN  Iterator.prototype.next()

Returns the next iteration result from iter.

procedure

(iterator-return iter [value]) → external/raw

  iter : iterator?
  value : any/c = (void)

 MDN  Iterator.prototype.return()

Asks iter to finish early and returns the resulting iteration record.

procedure

(iterator-symbol-iterator iter) → iterator?

  iter : iterator?

 MDN  Iterator

Returns iter itself, matching the behavior of [Symbol.iterator].

procedure

(iterator-dispose! iter) → void?

  iter : iterator?

 MDN  Symbol.dispose

Disposes an iterator by calling return() when the iterator provides it.
