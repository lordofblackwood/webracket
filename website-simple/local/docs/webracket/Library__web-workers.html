50 Library: web-workers🔗

 (require web-workers) package: web-workers

The web-workers module wraps a small, practical slice of the dedicated Web Worker API.

 MDN  Web Workers API

Read the MDN page first. The wrapper below gives you the WebRacket surface, while the MDN documentation explains worker loading, message passing, origin rules, and the distinction between classic and module workers.

Use web-workers when you want to:

  • create a dedicated worker from a script URL

  • send messages to the worker

  • terminate the worker

  • attach message and error handlers

50.1 Web Workers Quick Start🔗

(require web-workers)
 
(define w (make-worker "worker.js"))
 
(worker-post-message! w #(ping 42))
