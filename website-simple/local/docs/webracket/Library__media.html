43 Library: media🔗

 (include-lib media)

 Compile option:  --ffi dom

The media library wraps HTML media elements such as audio and video. Use it when you want to point an element at a source file, show controls, and read or adjust playback state from WebRacket.

Use media when you want to:

  • set up audio or video playback on the page

  • read or set the current playback position

  • toggle browser controls on a media element

  • start or pause playback

The library keeps the common play/pause controls and HTMLMediaElement properties on the WebRacket side, so you can work with checked values instead of raw browser objects.

value

media : any/c

This chapter documents the media wrapper library.

When a helper expects a browser string such as a media source, preload hint, codec type, or sink id, the wrapper also accepts a symbol and normalizes it to a string before calling the browser.

Some of the browser values that media elements expose are wrapped too: track lists, time ranges, media errors, and captured media streams are all represented with checked structs instead of raw browser objects. Individual AudioTrack, TextTrack, and VideoTrack values are wrapped the same way, so the track lists and addTextTrack() helper stay within WebRacket values. The attached MediaKeys object and the current source object are wrapped too, so the media wrapper stays within checked values at those edges as well.

43.1 Media Quick Start🔗

Start by creating a media element, giving it a source, and checking its playback position.

; Include the document and media wrapper libraries.
(include-lib document)
(include-lib media)
 
; Create an audio element we can configure.
(define player (document-create-element "audio"))
 
; Point the element at some media and show controls.
(media-set-src! player "/audio/theme.ogg")
(media-set-controls! player #t)
 
; Read the current playback time.
(media-current-time player)

The quick start shows the basic pattern: create a media element, point it at a source, and read or adjust playback state.

43.2 Media Example🔗

This example shows a small media setup that prepares an audio element and seeks it to a new position.

; Include the wrapper libraries used for the page and media.
(include-lib document)
(include-lib media)
 
; Create a media element and configure it for playback.
(define player (document-create-element "audio"))
 
(media-set-src! player "/audio/theme.ogg")
(media-set-controls! player #t)
 
; Read and then adjust the playback position.
(define before (media-current-time player))
(media-set-current-time! player (+ before 5))
 
; Check whether the browser still considers the element controlled.
(define controls? (media-controls? player))
 
(void controls? player)

When you only need a few helpers, the most useful entry points are media-src, media-set-src!, media-current-time, media-set-current-time!, media-controls?, and media-set-controls!.
