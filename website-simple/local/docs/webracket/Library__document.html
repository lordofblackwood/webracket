30 Library: document🔗

 (include-lib document)

 Compile option:  --ffi dom

The document library is the checked wrapper for the browser’s current page document.

Checked wrappers are small Racket values that stand in for browser objects and only accept the right kind of raw value at the boundary.

If you are new to browser programming, think of the document as the tree of things currently on the page. It is where the page’s elements live, and it is the starting point for finding or creating content.

Use Document when you want to:

  • look up the current page

  • find an element by id or CSS selector

  • create a fresh element before inserting it elsewhere

  • inspect the document head or body

The document library provides a checked wrapper for the current document, plus wrapped element helpers for lookup and selector queries.

These entries are checked structs: they wrap browser objects so you work with Racket predicates and accessors instead of raw browser values.

When a browser method expects a string, the wrapper also accepts a symbol and normalizes it to a string.

30.1 Document Quick Start🔗

Start by including the library, grabbing the current document, and finding a useful part of the page.

; Include the checked document wrapper library.
(include-lib document)
 
; Get the current document.
(define doc (Document))
 
; Look for the page body or another element you care about.
(define body (document-body))
 
; Create a new paragraph element for later use.
(define note (document-create-element "p"))

The quick start shows the three basic ideas: access the current document, inspect the existing page, and create a new element.

30.2 Document Example🔗

This example shows the usual pattern for page work: get the document, create a new node, and prepare it to be inserted into the page.

; Include the document wrapper library.
(include-lib document)
 
; Get the current document and its body element.
(define doc (Document))
(define body (document-body))
 
; Create a new element that can be configured before insertion.
(define note (document-create-element "p"))
 
; Use a selector when you need to find an existing part of the page.
(define main-area (document-query-selector "main"))

If you already know the page element you want, the most useful entry points are usually document-body, document-head, document-get-element-by-id, document-query-selector, and document-create-element.
