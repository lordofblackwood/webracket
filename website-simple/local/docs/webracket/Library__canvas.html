26 Library: canvas🔗

 (include-lib canvas)

 Compile option:  --ffi dom

The canvas library wraps HTML canvas elements and their 2D drawing contexts in checked values.

Canvas lets you draw pixels with shapes, text, and images. Use it when you want to paint directly on the page instead of building the interface out of HTML elements.

Use canvas when you want to:

  • create or inspect a canvas element

  • get a 2D rendering context

  • draw rectangles or text

  • clear or reshape the canvas surface

The library keeps canvas elements, 2D contexts, and the richer values they produce on the WebRacket side.

26.1 Canvas Quick Start🔗

Start by creating a canvas element, getting its 2D context, and drawing a filled rectangle.

; Include the document and canvas wrapper libraries.
(include-lib document)
(include-lib canvas)
 
; Create a new canvas element.
(define canvas-el (document-create-element "canvas"))
 
; Get the 2D drawing context from the canvas.
(define ctx (canvas-get-context canvas-el '2d))
 
; Draw a simple filled rectangle.
(canvas-2d-fill-rect ctx 10 10 120 50)

The quick start shows the usual pattern: create a canvas, ask for a context, and draw something simple.

26.2 Canvas Example🔗

This example shows how to add a canvas to the page and then paint it.

; Include the libraries needed for page insertion and drawing.
(include-lib document)
(include-lib element)
(include-lib canvas)
 
; Create and size a canvas element.
(define canvas-el (document-create-element "canvas"))
(set-attribute! canvas-el "width" "240")
(set-attribute! canvas-el "height" "120")
 
; Insert the canvas into the page body.
(append-child! (document-body) canvas-el)
 
; Get the 2D drawing context and draw a small scene.
(define ctx (canvas-get-context canvas-el '2d))
(canvas-2d-clear-rect ctx 0 0 240 120)
(canvas-2d-set-fill-style! ctx "hsl(210, 60%, 60%)")
(canvas-2d-fill-rect ctx 20 20 80 40)
(canvas-2d-set-stroke-style! ctx "black")
(canvas-2d-stroke-rect ctx 20 20 80 40)
(canvas-2d-begin-path ctx)
(canvas-2d-move-to ctx 20 80)
(canvas-2d-line-to ctx 100 80)
(canvas-2d-line-to ctx 60 100)
(canvas-2d-stroke ctx)
(canvas-2d-set-font! ctx "16px sans-serif")
(canvas-2d-set-fill-style! ctx "black")
(canvas-2d-fill-text ctx "Hello, canvas!" 20 112)

The main values are html-canvas-element? and canvas-rendering-context-2d?. Use html-canvas-element-raw or canvas-rendering-context-2d-raw only when you need to drop back to the browser object.

String-like arguments such as context identifiers and drawing modes accept either strings or symbols. Optional arguments use #f to mean that the argument is omitted.
