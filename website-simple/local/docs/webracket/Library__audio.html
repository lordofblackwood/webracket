25 Library: audio🔗

 (include-lib audio)

 Compile option:  --ffi audio

Web Audio lets you build sound graphs directly in the page. Instead of only playing back files, you can create oscillator sources, route signals through filters and gain nodes, and inspect the result with analysers.

Use audio when you want to:

  • synthesizers and tone generators

  • audio visualizers

  • music tools and loopers

  • low-latency signal routing

The audio library is the checked, high-level API for Web Audio programs in WebRacket. It sits on top of the lower-level ffi/audio.ffi bindings, but application code should normally use the audio-* functions documented on this page.

String-like audio arguments accept either strings or symbols, and the wrapper converts symbols to their string names. Optional arguments use #f to mean that the argument is omitted.

The audio-context-listener result is wrapped as an audio-listener value. Use audio-listener-raw only when you need the underlying browser object directly.

25.1 Audio Quick Start🔗

To use the audio API, create a context, create a source node, connect it to the destination, and start it.

; Include the audio library.
(include-lib audio)
 
; Create an audio context.
(define ctx (audio-context-new))
 
; Create an oscillator node.
(define osc (audio-context-create-oscillator ctx))
 
; Set the oscillator shape, connect it, and start it.
(audio-oscillator-node-set-type! osc 'sine)
(audio-node-connect osc (audio-context-destination ctx))
(audio-oscillator-node-start! osc)
