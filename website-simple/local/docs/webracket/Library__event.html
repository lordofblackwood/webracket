34 Library: event🔗

 (include-lib event)

 Compile option:  --ffi dom

The event library wraps browser events in checked values.

Events are the messages the browser sends when something happens: clicks, key presses, form submissions, pointer movement, and many other changes in the page.

Use event when you want to:

  • check whether a value is a browser event

  • read the event type string

  • stop the browser’s default action

  • branch on event kind inside a handler

The event library provides predicates and accessors for common browser events.

The message-event? and close-event? helpers cover browser MessageEvent and CloseEvent values, which are especially useful for WebSocket handlers.

34.1 Event Quick Start🔗

Start by including the library and writing a tiny handler that inspects the event before acting on it.

; Include the checked event wrapper library.
(include-lib event)
 
; Define a small handler that reads the event type.
(define (handle-event evt)
  (define kind (event-type evt))
  kind)
 
; The handler can be used from element or window event hooks.
(void handle-event)

This quick start shows the basic pattern: include the library, accept an event value, and inspect it with a checked helper.

34.2 Event Example🔗

This example shows the usual browser event workflow: recognize the event kind, stop the default action when needed, and continue with your own logic.

; Include the wrapper library.
(include-lib event)
 
; Handle a browser event in a small, readable function.
(define (handle-click evt)
  ; Read the browser event type.
  (define kind (event-type evt))
 
  ; Stop the browser from doing its default action.
  (prevent-default! evt)
 
  ; Return the event type so the caller can log it.
  kind)
 
; A caller can use the predicate to distinguish mouse events.
(define (handle-any-event evt)
  (when (mouse-event? evt)
    (handle-click evt)))
 
(void handle-click handle-any-event)

When you are writing event code, the most useful entry points are usually event?, mouse-event?, event-type, and prevent-default!.
