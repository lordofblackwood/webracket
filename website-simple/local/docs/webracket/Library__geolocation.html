38 Library: geolocation🔗

 (require geolocation) package: geolocation

The geolocation module wraps the browser Geolocation API. It provides a checked wrapper around navigator.geolocation and converts browser success/error callbacks into wrapped values.

 MDN  Geolocation API

Important browser constraints

  • Geolocation normally requires HTTPS or localhost.

  • Browsers may prompt the user before exposing location data.

  • Position reads are asynchronous and callback-driven.

38.1 Quick Start🔗

(require geolocation)
 
(define geo (geolocation))
 
(when geo
  (geolocation-get-current-position
   geo
   (lambda (position)
     (define coords
       (geolocation-position-coordinates position))
     (js-log (geolocation-coordinates-latitude coords)
             (geolocation-coordinates-longitude coords)))))
