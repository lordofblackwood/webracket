29 Library: compression-streams🔗

 (require compression-streams) package: compression-streams

The compression-streams module wraps the browser CompressionStream and DecompressionStream constructors. The API is stream-based: create a transform stream and pipe a browser ReadableStream through it.

 MDN  Compression Streams API

Read MDN first. Compression streams are asynchronous browser streams. This wrapper intentionally exposes the stream-level API; byte/string convenience helpers can be layered on later when the surrounding ReadableStream, Blob, and typed-array wrappers are broader.

29.1 Compression Streams Quick Start🔗

(require compression-streams)
 
(when (compression-stream-supported?)
  (define gz (make-compression-stream 'gzip))
  (compression-stream-readable gz)
  (compression-stream-writable gz))
