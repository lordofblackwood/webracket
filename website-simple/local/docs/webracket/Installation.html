3 Installation🔗

Set up WebRacket for both terminal and browser use.

3.1 Prerequisites🔗

You need:

  • wasm-tools (Bytecode Alliance) v1.243.0 or newer

  • node with WebAssembly exnref exception handling

  • Racket 9.0 or newer

  • raco-static-web

  • A local clone of the WebRacket repository

3.2 Installation Steps🔗

1. Install wasm-tools

Download the latest release: https://github.com/bytecodealliance/wasm-tools/releases

Extract and put it on your PATH, then verify:

tar -xvf wasm-tools-1.243.0-aarch64-macos.tar.gz
sudo mv wasm-tools /usr/local/bin/
wasm-tools
tar -xvf wasm-tools-1.243.0-aarch64-macos.tar.gz sudo mv wasm-tools /usr/local/bin/ wasm-tools

On macOS, if quarantine blocks execution:

sudo xattr -d com.apple.quarantine /usr/local/bin/wasm-tools
sudo xattr -d com.apple.quarantine /usr/local/bin/wasm-tools

2. Install Node.js

Download: https://nodejs.org/en/download

Use Node.js 24.15.0 or newer. Current Node 24 LTS and Node 26 enable WebAssembly exnref by default and need no extra flags.

Verify Node:

node --version
node -e "console.log('Node OK')"
node --version node -e "console.log('Node OK')"

If you use Node 22.x, or Node 24 before 24.15.0, run generated Node output with --experimental-wasm-exnref, or upgrade Node.

3. Install Racket

Install Racket 9.0 or newer: https://download.racket-lang.org/

4. Install raco-static-web

raco pkg install raco-static-web
raco static-web
raco pkg install raco-static-web raco static-web

5. Install nanopass

raco pkg install nanopass
raco pkg install nanopass

6. Clone WebRacket

git clone https://github.com/soegaard/webracket.git
git clone https://github.com/soegaard/webracket.git

7. Install the local checkout as package webracket

Run in the root of the cloned webracket repository:

raco pkg install --auto --name webracket .
raco pkg install --auto --name webracket .

8. Quick test

Serve examples and open one in your browser:

cd examples
raco static-web
cd examples raco static-web

Then open: http://localhost:8000/
