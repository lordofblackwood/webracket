Library: clipboard🔗

 (require clipboard) package: webracket

The clipboard module gives browser code access to plain-text clipboard reads and writes through navigator.clipboard.

 MDN  Clipboard API

Use clipboard when you want to:

  • check whether browser clipboard text support is available

  • read the current navigator.clipboard object as a wrapped value

  • start asynchronous plain-text clipboard reads

  • start asynchronous plain-text clipboard writes

Important browser constraints

  • Most browsers expose navigator.clipboard only in a secure context, typically HTTPS or localhost.

  • Clipboard reads and writes commonly require a user activation such as a button click.

  • Clipboard reads and writes are asynchronous and return js-promise? values.

String-like text arguments accept either strings or symbols. Symbols are converted with symbol->string before the browser call.

1 Clipboard Quick Start🔗

(require browser/dom
         clipboard
         js/promise)
 
(define clip (clipboard))
 
(when clip
  (js-promise-then
   (clipboard-write-text! clip "Hello from WebRacket")
   (lambda (ignored)
     (js-log "clipboard write finished")
     (void))))

2 Clipboard API🔗

procedure

(clipboard-supported?) → boolean?

 MDN  Navigator: clipboard property

Returns #t when the current browser exposes navigator.clipboard with the plain-text readText and writeText methods.

procedure

(clipboard) → (or/c #f clipboard?)

 MDN  Navigator: clipboard property

Returns the current browser Clipboard object wrapped in a checked value, or #f when the Clipboard API is not available in this environment.

procedure

(clipboard? v) → boolean?

  v : any/c
Returns #t when v is a wrapped Clipboard value with plain-text read and write support.

procedure

(clipboard-raw value) → external/raw

  value : clipboard?
Returns the wrapped raw browser Clipboard object.

procedure

(clipboard-read-text value) → js-promise?

  value : clipboard?

 MDN  Clipboard: readText() method

Starts an asynchronous clipboard text read and returns a wrapped JavaScript Promise.

procedure

(clipboard-write-text! value text) → js-promise?

  value : clipboard?
  text : (or/c string? symbol?)

 MDN  Clipboard: writeText() method

Starts an asynchronous clipboard text write and returns a wrapped JavaScript Promise.
