11 Callback Source-Map Tool - Revised🔗

The callback source-map tool helps connect a browser or Node callback error back to the WebRacket source that produced the callback.

When a generated callback fails, WebRacket may print a debug label such as label.4054. The compiler records those labels in the generated .wasm.map.sexp file. Use tools/find-callback-source.rkt to look up the label and print the corresponding source location.

11.1 When To Use It🔗

Use this tool when a callback error includes a debug-id:

  WebRacket callback error

    kind: arity-mismatch

    name: on-click

    id: 0

    debug-id: label.4054

    expected: 0

    argc: 1

    detail: callback arity mismatch

The label is only meaningful for the build that produced it. Use the .wasm.map.sexp file generated with the failing .wasm file.

11.2 Basic Use🔗

Run the tool with the map file and the label:

racket tools/find-callback-source.rkt path/to/program.wasm.map.sexp label.4054
racket tools/find-callback-source.rkt path/to/program.wasm.map.sexp label.4054

The output includes the label, source path, source line and column, span, and any alias target recorded with same-as.

Example output:

  label: label.4054

  source: /path/to/file.rkt:107:2

  span: 135

11.3 Showing The Source Form🔗

If the map was generated with form payloads, pass --show-form to print the recorded source form too:

racket tools/find-callback-source.rkt --show-form path/to/program.wasm.map.sexp label.4054
racket tools/find-callback-source.rkt --show-form path/to/program.wasm.map.sexp label.4054

Example output:

  label: label.4054

  source: /path/to/file.rkt:107:2

  span: 135

  form: "(let-values ...)"

Source locations do not require form payloads. If the map was generated without --label-map-forms, the location lookup still works, but --show-form may have no form to print.

11.4 Typical Workflow🔗

  • Reproduce the callback error.

  • Copy the debug-id label from the error message.

  • Find the .wasm.map.sexp file produced with the failing build.

  • Run tools/find-callback-source.rkt with the map file and label.

  • Use --show-form when you need to inspect the recorded form and the map was generated with form payloads.

11.5 Notes🔗

  • The tool is read-only. It does not modify source files or map files.

  • Labels are build-local. Rebuilds can assign different labels.

  • If the tool reports same-as, that means the label is an alias for another recorded label.

  • A missing label usually means the wrong .wasm.map.sexp file was used, or the error came from a different build.
