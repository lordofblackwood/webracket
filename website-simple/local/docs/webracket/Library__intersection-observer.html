42 Library: intersection-observer🔗

 (require intersection-observer)
  package: intersection-observer

The intersection-observer module wraps the browser IntersectionObserver API. It is useful when code should react to whether an element is visible inside the viewport or inside a custom root.

 MDN  Intersection Observer API

42.1 Quick Start🔗

(require browser/document
         browser/dom
         intersection-observer)
 
(define target
  (document-query-selector "#watched"))
 
(define observer
  (make-intersection-observer
   (lambda (entries observer)
     (define first-entry (vector-ref entries 0))
     (when (intersection-observer-entry-is-intersecting? first-entry)
       (js-log "target is visible")))))
 
(intersection-observer-observe! observer target)

Use intersection-observer when you want to:

  • observe whether an element enters or leaves view

  • react to browser-generated visibility changes instead of polling

  • inspect wrapped IntersectionObserverEntry values

Creates a wrapped browser observer. The callback receives a vector of intersection-observer-entry? values and the wrapped observer.
