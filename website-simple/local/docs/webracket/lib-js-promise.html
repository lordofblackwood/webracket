Library: js/promise🔗

 (require js/promise) package: webracket

The js/promise module wraps JavaScript Promise values and provides a small set of helper functions for attaching fulfillment, rejection, and cleanup handlers from WebRacket code.

Use js/promise when you want to:

  • recognize wrapped JavaScript Promise-like values

  • attach then, catch, and finally handlers without reflective string method calls

  • work with Promise-returning APIs such as Clipboard, Fetch, and media methods

1 Quick Start🔗

(require js/promise)
 
(define ready
  (js-promise-resolved "done"))
 
(js-promise-then
 ready
 (lambda (value)
   (js-log value)
   (void)))

The most common pattern is:

  • get a js-promise? value back from a browser API

  • attach a success handler with js-promise-then

  • optionally attach error cleanup with js-promise-catch or js-promise-finally

  v : any/c
Returns #t when v is a wrapped Promise-like value.

procedure

(js-promise-wrap raw) → js-promise?

  raw : external/raw
Wraps a Promise-like browser value.

procedure

(js-promise-unwrap promise) → external/raw

  promise : js-promise?
Returns the wrapped raw Promise-like value.

procedure

(js-promise-resolved value) → js-promise?

  value : any/c
Creates an already-resolved JavaScript Promise.

procedure

(js-promise-rejected value) → js-promise?

  value : any/c
Creates an already-rejected JavaScript Promise.

procedure

(js-promise-then promise    
  on-fulfilled    
  [on-rejected]) → js-promise?
  promise : js-promise?
  on-fulfilled : (or/c procedure? external?)
  on-rejected : (or/c #f procedure? external?) = #f
Attaches fulfillment and optional rejection handlers and returns the chained JavaScript Promise.

procedure

(js-promise-catch promise on-rejected) → js-promise?

  promise : js-promise?
  on-rejected : (or/c procedure? external?)
Attaches a rejection handler and returns the chained JavaScript Promise.

procedure

(js-promise-finally promise on-finally) → js-promise?

  promise : js-promise?
  on-finally : (or/c procedure? external?)
Attaches a cleanup handler and returns the chained JavaScript Promise.
