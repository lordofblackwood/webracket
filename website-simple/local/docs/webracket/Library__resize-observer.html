46 Library: resize-observer🔗

 (require resize-observer) package: resize-observer

The resize-observer module wraps the browser ResizeObserver API. It is useful when code should react to size changes in an element without polling layout continuously.

 MDN  Resize Observer API

46.1 Quick Start🔗

(require browser/document
         browser/dom
         resize-observer)
 
(define target
  (document-query-selector "#panel"))
 
(define observer
  (make-resize-observer
   (lambda (entries observer)
     (define first-entry (vector-ref entries 0))
     (js-log "panel resized"
             (resize-observer-entry-content-rect first-entry)))))
 
(resize-observer-observe! observer target)

46.2 API🔗

procedure

(resize-observer-supported?) → boolean?

Returns #t when the browser exposes ResizeObserver.

procedure

(resize-observer raw) → resize-observer?

  raw : external/raw
Wraps a raw browser ResizeObserver value.

procedure

(resize-observer? v) → boolean?

  v : any/c
Returns #t when v is a wrapped observer.

procedure

(resize-observer-raw value) → external/raw

  value : resize-observer?
Returns the wrapped raw browser observer.

procedure

(make-resize-observer-options box) → resize-observer-options?

  box : (or/c #f string? symbol?)
Creates options for ResizeObserver.observe().

procedure

(make-resize-observer callback) → resize-observer?

  callback : (or/c procedure? external?)
Creates a wrapped browser observer. The callback receives a vector of resize-observer-entry? values and the wrapped observer.

procedure

(resize-observer-observe! observer    
  target    
  [options]) → void?
  observer : resize-observer?
  target : (or/c dom-element? external?)
  options : (or/c #f resize-observer-options?) = #f
Starts observing target.

procedure

(resize-observer-unobserve! observer    
  target) → void?
  observer : resize-observer?
  target : (or/c dom-element? external?)
Stops observing target.

procedure

(resize-observer-disconnect! observer) → void?

  observer : resize-observer?
Disconnects the observer from all targets.

struct

(struct resize-observer-entry (raw)
    #:extra-constructor-name make-resize-observer-entry)
  raw : external/raw
Wraps a browser ResizeObserverEntry value.

procedure

(resize-observer-entry-target entry) → dom-element?

  entry : resize-observer-entry?
Returns the observed target element.

procedure

(resize-observer-entry-content-rect entry) → dom-rect?

  entry : resize-observer-entry?
Returns the current content rectangle for the entry.
