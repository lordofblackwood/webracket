22 Library: sxml🔗

 (include-lib sxml)

The sxml library converts SXML trees into HTML strings. It is a small helper for programs that want to build HTML with plain Racket data instead of writing string concatenation by hand.

SXML represents HTML as nested lists. The first element of a list is the tag name, an optional attribute list headed by the symbol @ holds attributes, and the remaining elements are children. Text content may be strings, numbers, or symbols.

Use sxml when you want to:

  • turn a small SXML tree into an HTML string

  • build static HTML fragments with Racket data

  • escape text and attribute values automatically

22.1 Quick Start🔗

Start by including the library and converting a tiny page fragment.

(include-lib sxml)
 
(sxml->html
 `(div (@ (class "notice"))
       (h1 "Hello")
       (p "This HTML was built from SXML.")))

22.2 Examples🔗

The converter handles both a single node and a list of sibling nodes. One common use is to build an HTML string and then place it into the current page body.

(include-lib document)
(include-lib element)
(include-lib sxml)
 
(define page
  (sxml->html
   `(div (@ (class "card"))
         (h1 "Hello")
         (p "This page was built from SXML."))))
 
(define body (document-body))
(when body
  (element-set-inner-html! body page))

The HTML string can also be used on its own when you just want the serialized markup.

(sxml->html
 `(div (@ (class "card"))
       (p "First paragraph.")
       (p "Second paragraph.")))

  "<div class=\"card\"><p>First paragraph.</p><p>Second paragraph.</p></div>"

Text and attribute values are escaped automatically.

(sxml->html
 `(p "Use < and > safely, and keep \"quotes\" in attributes."
     (@ (title "A \"quoted\" title"))))

  "<p title=\"A &quot;quoted&quot; title\">Use &lt; and &gt; safely, and keep &quot;quotes&quot; in attributes.</p>"

22.3 API Reference🔗

procedure

(sxml->html sxml) → string?

  sxml : any/c
Converts an SXML tree or list of SXML nodes into an HTML string.
