49 Library: web-speech🔗

 (require web-speech) package: web-speech

The web-speech module wraps browser speech synthesis: creating utterances, speaking/canceling them, reading voices, and setting basic utterance options.

 MDN  Web Speech API

Read MDN first. Web Speech support varies substantially between browsers. This first wrapper focuses on SpeechSynthesis; speech recognition is exposed only as a support predicate because browser support and prefixes are still uneven.

49.1 Web Speech Quick Start🔗

(require web-speech)
 
(define synth (speech-synthesis))
 
(when synth
  (define utterance
    (make-speech-utterance
     "Hello from WebRacket"
     (make-speech-utterance-options "en-US" 1 1 1)))
  (speech-synthesis-speak! synth utterance))

49.2 Web Speech API🔗

procedure

(web-speech-synthesis-supported?) → boolean?

 MDN  SpeechSynthesis

Returns #t when speech synthesis and SpeechSynthesisUtterance are available.

procedure

(web-speech-recognition-supported?) → boolean?

 MDN  SpeechRecognition

Returns #t when the browser exposes SpeechRecognition or webkitSpeechRecognition. Recognition construction is not wrapped in this first pass.

procedure

(speech-synthesis) → (or/c #f speech-synthesis?)

Returns the browser SpeechSynthesis object wrapped in a checked value, or #f when unsupported.

procedure

  v : any/c
Returns #t for wrapped SpeechSynthesis values.

procedure

(speech-synthesis-raw value) → external/raw

  value : speech-synthesis?
Returns the wrapped raw SpeechSynthesis object.

procedure

(make-speech-utterance-options [lang 
  volume 
  rate 
  pitch]) 
 → speech-utterance-options?
  lang : (or/c #f string? symbol?) = #f
  volume : (or/c #f (real-in 0 1)) = #f
  rate : (or/c #f (real-in 0.1 10)) = #f
  pitch : (or/c #f (real-in 0 2)) = #f
Builds checked options for make-speech-utterance. The defaults leave browser defaults unchanged.

procedure

(make-speech-utterance text [options]) → speech-utterance?

  text : (or/c string? symbol?)
  options : (or/c #f speech-utterance-options?) = #f

 MDN  SpeechSynthesisUtterance

Creates a browser utterance. Symbols are converted with symbol->string.
