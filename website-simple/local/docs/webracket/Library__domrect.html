32 Library: domrect🔗

 (include-lib domrect)

 Compile option:  --ffi dom

The domrect library is the checked wrapper for rectangle geometry values coming back from browser layout APIs.

A DOMRect describes the position and size of a box on the page. It is useful when you want to know where something appears on screen and how wide or tall it is.

Use domrect when you want to:

  • read the left and top coordinates of a rectangle

  • read its width and height

  • work with geometry returned by browser layout calls

The domrect library provides a checked wrapper for DOMRect geometry values.

32.3 DOMRect Quick Start🔗

Start by taking a rectangle returned by another DOM helper and reading its basic measurements.

; Include the DOM, element, and DOMRect wrapper libraries.
(include-lib document)
(include-lib element)
(include-lib domrect)
 
; Find an element whose rectangle we want to inspect.
(define card (document-query-selector ".card"))
 
; Ask the browser for the rectangle around that element.
(define rect (get-bounding-client-rect card))
 
; Read the rectangle's position and size.
(list (dom-rect-left rect)
      (dom-rect-top rect)
      (dom-rect-width rect)
      (dom-rect-height rect))

The quick start shows the basic pattern: keep the rectangle, then read the coordinates you need.

32.4 DOMRect Example🔗

This example shows the normal flow: find an element, ask the browser for its bounding rectangle, and then read the measurements with the domrect helpers.

; Include the DOM and rectangle libraries.
(include-lib document)
(include-lib element)
(include-lib domrect)
 
; Find a page element whose geometry we want to inspect.
(define card (document-query-selector ".card"))
 
; Ask the browser for the rectangle around that element.
(define rect (get-bounding-client-rect card))
 
; Read the rectangle values in a Racket-friendly way.
(list (dom-rect-left rect)
      (dom-rect-top rect)
      (dom-rect-width rect)
      (dom-rect-height rect))

If all you need is geometry, the main entry points are dom-rect-left, dom-rect-top, dom-rect-width, and dom-rect-height.
