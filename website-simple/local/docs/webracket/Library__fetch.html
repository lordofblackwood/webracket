35 Library: fetch🔗

 (include-lib fetch)

 Compile option:  --ffi dom

The Fetch API is the browser’s modern networking interface. It lets a page create Request values, start network operations, and inspect Response and Headers data without dropping to lower-level XHR code.

In WebRacket, the fetch library provides checked wrappers for the browser Fetch API. The library keeps the common request, response, and headers objects readable from Racket code while still handing the browser raw objects where needed.

 MDN  Fetch API

Use fetch when you want to:

  • start a browser fetch request

  • wrap and inspect Request, Response, and Headers values

  • read status, URL, and header information from a response

  • construct requests or headers from Racket values

The library exposes checked wrapper structs for request, response, and headers values. Use the fetch-request-raw, fetch-response-raw, and fetch-headers-raw accessors only when you need to hand the browser object to a lower-level helper.

 MDN  Fetch API

String-like arguments accept either strings or symbols. Optional arguments use #f to mean that the argument is omitted.

35.1 Fetch Quick Start🔗

; Include the Fetch wrapper library.
(include-lib fetch)
 
; Create a request and a header set.
(define req (make-fetch-request "/api/status"))
(define hdrs (make-fetch-headers))
 
; Perform the request and inspect the response later.
(define resp (fetch req))
 
(void req hdrs resp)
