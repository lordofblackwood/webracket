# Hello World 2 Example

## Build

From this folder:

```sh
./compile.sh
```

## Serve

From this folder:

```sh
python3 -m http.server
```

## Open

Open:

- `http://localhost:8000/generated/hello-world.html`

This example also calls `(js-log "Hello!")`, which prints `Hello!` in the browser's JavaScript console.
