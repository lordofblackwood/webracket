# Clipboard Example

## Build

From this folder:

```sh
./compile.sh
```

## Serve

From this folder:

```sh
python3 -m http.server
```

## Open

Open:

- `http://localhost:8000/generated/clipboard-demo.html`

## Notes

- The Clipboard API normally requires a secure context.
- Reading and writing are typically allowed only in a user-initiated event such as a button click.
